In plain words

BrowserPod is free for any use — personal, commercial and production — as long as you credit it.

- Free for everyone. Individuals, companies of any size, open-source projects, educators and AI agents can use BrowserPod in development, in production, in commercial products, in internal tools and in SaaS. There is no usage limit and no fee.
- Credit BrowserPod. Show "Powered by BrowserPod" with a link to browserpod.io where your pods run. Tools and agents that run pods without a user interface credit BrowserPod in their documentation or README. Edge Pro includes the Community Licence without attribution.
- Load it from us. Load the runtime and its disk images from our servers. Do not copy, host, mirror or bundle them. Self-hosting, vendoring and redistribution need an Enterprise Licence.
- It doesn't phone home. The runtime only downloads its own files and disk data from us. It sends no telemetry, licence checks or usage data. Those downloads tell our servers the user's IP address and the page's origin; the Runtime Privacy Policy (https://browserpod.io/runtime-privacy) explains what we do with them.
- Versions stay put. Each published runtime version stays available, unchanged, at its own address, unless it has a critical security flaw.
- Networking is separate. BrowserPod Edge (Portals, outbound networking through our network, TCP) is an optional service under its own Terms of Service (https://browserpod.io/terms). Runtime versions before 3.5.0 only start with an API key, so they can only be used together with Edge.
- No warranty. BrowserPod is provided as is. Community support is on Discord.
